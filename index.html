Mejora tu documento un cambio comprobado cada vez

Una memoria, una propuesta, un informe o un artículo. Un evaluador de IA lo puntúa con tus criterios; otro agente propone un cambio pequeño; el cambio solo se queda si mejora de verdad y no estropea nada. Repite hasta llegar a tu objetivo, y cada intento, bueno o malo, queda registrado.

Tienes una sesión anterior guardada en este navegador.

Más largo no es mejor: solo cuenta lo que mejora según tus criterios.

Cómo decide si un cambio se queda

1
Se mideEl evaluador puntúa cada criterio varias veces y se queda con la mediana, para no fiarse de una lectura.
2
Se proponeOtro agente cambia un fragmento concreto para mejorar el criterio más flojo. Nunca reescribe el documento entero.
3
Tres filtrosMejora lo suficiente, ningún criterio empeora y un juez que no sabe cuál es cuál prefiere la versión nueva.
4
Se queda o se deshaceSi falla un filtro, se deshace, pero se recuerda para no repetirlo. Todo forma un grafo de intentos.

Dos defensas contra las trampas

Criterios ocultos

Lo que el agente no veHay criterios que el evaluador usa pero el agente que cambia el texto desconoce, como «sin relleno». Si la nota visible sube y la oculta baja, la app te avisa: el agente estaría complaciendo al evaluador, no mejorando el texto.

Textos protegidos

Lo que no se puede tocarCifras, nombres o citas que eliges se comprueban con código tras cada cambio. Si alguno desaparece o cambia, el cambio se deshace sin gastar ni una consulta.
